Koneksi Live Google Sheets

Dashboard ini menarik data langsung dari Google Sheets secara Read-Only melalui endpoint Google Visualization API tanpa memerlukan server tambahan.

Cara Mengaktifkan Sinkronisasi Live (1 Kali Saja):
  1. Buka Google Sheet Personal Finance Command Center Anda.
  2. Klik tombol hijau Share (Bagikan) di pojok kanan atas.
  3. Pada bagian General access, ubah dari Restricted menjadi Anyone with the link (Siapa saja yang memiliki link) dengan peran Viewer (Pelihat).
  4. Klik Done, lalu tekan tombol Simpan & Hubungkan di bawah ini.
